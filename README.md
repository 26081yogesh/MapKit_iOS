# 🗺️ Landmarks Exploration App

An iOS application built using **SwiftUI** and **MapKit** that allows users to explore famous landmarks across India through an interactive map experience.

---

## ✨ Features

- Built completely using SwiftUI
- Native MapKit integration
- Custom map markers
- Dynamic camera updates
- Smooth animations & transitions
- Locations dropdown list
- MVVM Architecture
- Modern state management using `@Observable`

---

## 🛠️ Tech Stack

- Swift
- SwiftUI
- MapKit
- MVVM
